## pf a11y at-point

Show the accessible object at screen coordinates

```
pf a11y at-point [X Y] [flags]
```

### Options

```
  -h, --help    help for at-point
      --json    write machine-readable JSON
      --x int   screen x coordinate
      --y int   screen y coordinate
```
