## pf input drag-and-drop

Drag from one coordinate to another (press, move, release)

```
pf input drag-and-drop [flags]
```

### Options

```
  -h, --help     help for drag-and-drop
      --x1 int   start x
      --x2 int   end x
      --y1 int   start y
      --y2 int   end y
```
